# xqisie

Detect the browser from a user agent string, and send visitors on Internet Explorer to a
"please upgrade" page.

[查看中文文档](./zh.md)

## Install

**Browser** — the UMD build exposes `window.xqisie`:

```html
<script src="https://unpkg.com/xqisie@0.1.0/lib/xqisie.min.js"></script>
```

**ES module** — both a default and named exports are available:

```html
<script type="module">
    import xqisie from 'https://unpkg.com/xqisie@0.1.0/lib/xqisie-esm.min.mjs';
    // or: import { check, goLink } from 'https://unpkg.com/xqisie@0.1.0/lib/xqisie-esm.min.mjs';
</script>
```

**Node / bundler**:

```sh
npm install xqisie
```

```js
const xqisie = require('xqisie');
// or: import xqisie from 'xqisie';
```

## Usage

### check(userAgent?)

Returns one of `'Chrome'`, `'IE'`, `'Firefox'`, `'Opera'`, `'Safari'`, or `''` when nothing
matches.

```js
const browser = xqisie.check();
console.log('Browser is:', browser);
```

Pass a user agent string to inspect a specific request instead of the current browser. When an
argument is supplied, `navigator` is never read — so this is safe on the server:

```js
const http = require('http');
const xqisie = require('xqisie');

http.createServer((req, res) => {
    res.end('browser is: ' + (xqisie.check(req.headers['user-agent']) || 'unknown'));
}).listen(3000, 'localhost');
```

Detection order matters, and it is deliberate: Opera is tested before Chrome because its UA
carries both, and Safari is tested last because nearly every WebKit UA contains `Safari`.

### goLink(url?)

Sends the current page to `url` (default `../page/`) **only** when the browser is IE. Returns a
boolean saying whether it navigated, and never throws — under Node or in a Worker there is no
`location`, so it simply reports `false`.

```js
xqisie.goLink('./page/index.html');
```

### The tip pages

`page/` holds a ready-made "your browser is too old" page (`index.html`), a redirect shim
(`js/index.js`), and its stylesheet and icons. Copy that directory into your site and point
`goLink()` at it:

```js
xqisie.goLink('/page/');
```

The shim reads `?url=` by name, accepts only `http:` and `https:` targets (so `javascript:` and
`data:` URLs are refused), and works on IE 11, which has neither `URLSearchParams` nor `URL`.

## Return values and limitations

| User agent contains | `check()` returns |
| --- | --- |
| `OPR/` or `Opera` | `'Opera'` |
| `Trident` or `MSIE` | `'IE'` |
| `Chrome` | `'Chrome'` |
| `Firefox` | `'Firefox'` |
| `Safari` | `'Safari'` |
| none of the above | `''` |

Known limitations, kept stable on purpose:

- **Edge reports `'Chrome'`.** Modern Edge carries `Chrome/` in its UA. Adding a sixth return
  value would break any caller switching on the current five.
- **iOS browsers report `'Safari'`.** Chrome (`CriOS/`) and Firefox (`FxiOS/`) on iOS both carry
  `Safari/`.
- **IE is detected from `Trident`/`MSIE` alone**, which covers IE 6 through 11 without reading
  the non-standard `navigator.appVersion`.

## View xqisie

```sh
npm run test:browser
```

Then open <http://127.0.0.1:4001/test/>. The index links one page per consumption path — UMD
readable, UMD minified, ESM readable, ESM minified — plus the tip pages. Each check page runs
its own suite against the committed bundle and shows `PENDING`, `PASS`, or `FAIL` next to every
check, then leaves an interactive demo on screen.

## Development

`src/index.js` is the only hand-written source. Everything in `lib/` is generated by
`scripts/build.mjs` and committed so the CDN paths keep working.

```sh
npm run build          # regenerate lib/ from src/
npm run check:dist     # fail if lib/ is out of date with src/
npm test               # node --test, rebuilds lib/ first
npm run test:browser   # serve the test pages
npm run test:browser:check   # run every page in headless Chrome/Edge
npm run verify         # check:dist + test + headless browser run
```

`src/index.js` is deliberately a plain ES5 script: the build wraps that body in both the UMD and
the ESM shell, so it must not contain `import`/`export`. ES5 is also a hard requirement — this
library has to execute inside the old browsers it detects.
